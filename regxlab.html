02 — Strings First

Standard string functions

Before reaching for regex, JavaScript already has tools for exact, fixed-text searches. These are fast and readable for simple cases.

Search exact text

text.includes("JavaScript");
text.startsWith("I");
text.endsWith("Script");

Extract or split

text.slice(7, 17);
text.substring(7, 17);
text.split(" ");

03 — The Key Shift

Regex generalizes string functions

String methods search for one fixed value. Regex searches for a reusable shape — the same pattern can match millions of different strings.

GoalString FunctionRegex Template
Contains exact wordtext.includes("cat")/cat/
Starts with Hellotext.startsWith("Hello")/^Hello/
Ends with periodtext.endsWith(".")/\.$/
Find any numbermanual loop/\d+/
Find date shapemanual logic/\d{4}-\d{2}-\d{2}/
Key shift: From "find this exact value" → to "find anything that fits this shape."
04 — Categories

Regex in four intuitive categories

Every regex pattern is a combination of these four building blocks.

A · Characters — What kind?

\d digit \w word char \s whitespace . any char 
\d   → 0–9
\w   → a–z A–Z 0–9 _
\s   → space, tab, newline

B · Quantity — How many?

+ one or more * zero or more ? optional {n} exactly n 
\d+    → one or more digits
\d{4}  → exactly 4 digits
\d{2,5} → 2 to 5 digits

C · Groups — Which choices?

[abc] set [A-Z] range (a|b) or 
[aeiou]    → any vowel
[A-Z]      → uppercase letter
(cat|dog)  → cat or dog

D · Position — Where?

^ start $ end \b word boundary 
^Hello   → line starts with Hello
\.$      → line ends with period
\bcat\b  → whole word cat only

Structure levels — what each level looks like as regex

LevelPatternMeaning
Character/\d/one digit
Word/\b\w+\b/one full word
Sentence/[A-Z][^.!?]*[.!?]/uppercase start → punctuation end
Line/^.+$/gmeach non-empty line
Paragraph/[^\n]+(?:\n(?!\n)[^\n]+)*/gblock separated by blank lines

07 — Reference

Cheat sheet

Character classes

\ddigit 0–9
\wletter, digit, or _
\swhitespace
.any char (except newline)
[A-Z]uppercase letter range
[^abc]not a, b, or c

Quantity

+one or more
*zero or more
?zero or one (optional)
{n}exactly n times
{m,n}between m and n times

Position anchors

^start of line / text
$end of line / text
\bword boundary

Common templates

\d+any number
\b\w+\bwhole word
\d{4}-\d{2}-\d{2}date YYYY-MM-DD
^\S+@\S+\.\S+$email shape
\bcat\bwhole word "cat"
