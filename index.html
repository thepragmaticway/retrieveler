Explore Data Retrieval with Retrieveler

Retrieveler (data retrieval learner) teaches how data is stored and retrieved in Relational, Hierarchical, and Graph structures through interactive labs. Beyond retrieval, we emphasize the importance of data security across storage, transfer, and access. Use the labs below to compare retrieval approaches, understand security best practices, and practice with real examples.

CSS Selector Learner

Practice hierarchical retrieval using HTML selectors and see how parent-child, ancestor-descendant, and attribute-based selection works in a DOM-like tree.

Open CSS Selector Learner

Object Lab

Inspect object-style structure and retrieval patterns through an interactive DOM inspector experience that connects conceptual hierarchy to real HTML objects.

Open Object Lab

Regex Lab

Explore text retrieval with regular expressions and learn how pattern matching can extract structured information from strings.

Open Regex Lab

Crypto Lab

Understand data security fundamentals including secure storage, encrypted transfer, and secure access controls. Explore how cryptographic principles protect data throughout its lifecycle.

Open Crypto Lab

Search Lab

Learn how linear search, binary search, and hash-based lookup retrieve data, then compare their real-world tradeoffs in speed, preprocessing cost, and scalability.

Open Search Lab

IPC Lab

Explore how operating systems let processes communicate through pipes, sockets, TCP, and HTTP, then practice inspecting real request and response flows.

Open IPC Lab

IPC Hands-On

Run real pipes and TCP sockets with the small Node.js CLIs in ipc/ — regxer, socketer, http-socketer, http-server, and the Express sample server.

Open IPC Hands-On

HTTP Capstone

Capstone for the IPC series — learn the shape of HTTP request and reply, then build the four CRUD verbs against a small Express auth app with HTML forms and AJAX.

Open HTTP Capstone

Video Foundations

Go from raw pixels to real-time streams — the concepts and tooling behind every video management system. Containers, codecs, compression, FFmpeg transcoding, and RTSP streaming.

Open Video Foundations

WebRTC Publishing Lab

Learn how a browser captures camera or screen, publishes it to MediaMTX over WebRTC, and makes the stream available for playback over multiple protocols.

Open WebRTC Publishing Lab

Tip: Start with the hierarchical examples to build intuition, then compare how relational and graph concepts differ in how they store and retrieve related data.
